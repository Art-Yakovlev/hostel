# Моделирование бизнес-процессов хостела

Учебный проект по анализу и моделированию бизнес-процессов организации, предоставляющей услуги хостела.

Цель проекта — описать текущий процесс обслуживания гостей, выявить проблемные места и разработать модель целевого состояния с учётом возможностей автоматизации.

## О проекте

В рамках проекта рассмотрены основные процессы обслуживания гостей: от оформления бронирования до выселения и подготовки периодической отчётности. На основе моделей текущего состояния (**AS IS**) определены проблемы ручной обработки данных и предложен вариант целевого состояния (**TO BE**) с централизацией данных в PMS-системе TravelLine.

> **Статус проекта:** учебный. Предложенные решения являются проектными и не рассматриваются как фактически внедрённые.

## Цели и задачи

- Проанализировать процесс предоставления услуг хостела.
- Построить модели текущего состояния бизнес-процессов (**AS IS**).
- Выявить риски, связанные с ручной обработкой данных и использованием нескольких инструментов учёта.
- Разработать модели целевого состояния (**TO BE**).
- Сопоставить текущий и целевой процессы.

## Область анализа

В проекте рассмотрены следующие процессы:

1. Оформление бронирования.
2. Оформление заселения.
3. Предоставление дополнительных услуг.
4. Оформление выселения.
5. Формирование отчётности за период.

## Результаты проекта

- Подготовлены модели **AS IS** и **TO BE** на верхнем уровне и по основным подпроцессам.
- Описаны ключевые риски текущей организации работы.
- Представлено целевое направление совершенствования процессов за счёт централизации данных и автоматизации отдельных операций.

## Структура проекта

Материалы проекта организованы по следующим разделам:

- **Анализ проекта** — краткое описание задачи, выявленных проблем и предлагаемых изменений.
- **`AS_IS/`** — модели текущего состояния бизнес-процессов.
- **`TO_BE/`** — модели целевого состояния бизнес-процессов.

Названия папок в этом описании приведены в качестве ориентиров; при необходимости замените их на фактические имена каталогов в репозитории.

## Используемые понятия

- **AS IS** — описание того, как процесс организован в текущем состоянии.
- **TO BE** — описание предлагаемого целевого состояния процесса.
- **PMS (Property Management System)** — система управления объектом размещения.
